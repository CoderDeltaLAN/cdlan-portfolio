# CDLAN Portfolio

Professional public portfolio website for CDLAN / Yosvel Delta.

This repository is built from scratch as a clean, auditable GitHub Pages portfolio for:

- applied AI systems;
- automation;
- RAG;
- AI agents;
- internal systems;
- technical documentation;
- static websites without backend for businesses, professionals and local establishments.

## Status

Current phase: clean local bootstrap.

The final visual landing page is not integrated yet. Any provisional HTML is treated only as visual reference until it passes content, security, accessibility and claims review.

## Public / private boundary

This repository is public frontend only.

Allowed here:

- brand presentation;
- public portfolio;
- service descriptions;
- public contact information;
- static HTML, CSS and JavaScript;
- public documentation;
- non-sensitive project summaries.

Not allowed here:

- secrets;
- API keys;
- tokens;
- private prompts;
- real N8N workflow exports;
- backend internals;
- SaaS internals;
- client data;
- private commercial strategy;
- unverified claims.

## Services represented

CDLAN focuses on:

- AI diagnosis and process review;
- RAG/document intelligence;
- N8N automation and workflow design;
- AI agents and assistants with clear boundaries;
- operational documentation;
- static professional websites without backend for businesses and establishments;
- maintenance and continuous improvement.

## Working method

After the first local bootstrap commit, all future changes must follow:

- branch per phase;
- no direct work on main;
- no `git add .`;
- local checks before commit;
- strong pre-push check;
- pull request;
- green CI;
- clean merge;
- final verification.
