# Publication Checklist

Before publishing a final page:

- No secrets.
- No private prompts.
- No real automation endpoints.
- No client data.
- No backend internals.
- No SaaS internals.
- No false claims.
- No exaggerated AI promises.
- No unapproved phone number.
- No broken links.
- No tracking unless explicitly approved.
- No external scripts unless reviewed.
- Contact information confirmed.
- GitHub URL confirmed.
- Accessibility basics reviewed.
- Mobile layout reviewed.
- Performance reviewed.
- HTML validated.
- CSS reviewed.
- JavaScript reviewed.
- CI green.
- Git status clean.
